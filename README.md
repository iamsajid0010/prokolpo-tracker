# Prokolpo Tracker (প্রকল্প ট্র্যাকার)
Static site. Synthetic demo data, not real government records. No build step.
Deploy: upload this folder's contents to a GitHub repo and import it in Vercel (Framework: Other), or enable GitHub Pages.
Routes: /app /demo-user /demo-admin /admin /data /security /architecture /presentation /pitchdeck /audit /prompt /docs
Local test: python3 -m http.server 8000, then open http://localhost:8000/app/
