Audit

Run the audit with JavaScript enabled. The audit runs real automated checks in your browser (fetching each route, reading resource timing, recomputing rules) and reports pass or fail with evidence. The score is passed divided by total, computed at run time. These are the planned checks:

  1. All 12 routes reachable (fetch)
  2. No external network requests (resource timing)
  3. Content-Security-Policy meta on every route
  4. localStorage works
  5. Anomaly banner equals sum of flagged row excess
  6. Disbursement never above budget
  7. Deadline logic uses the current date
  8. Seed dates are day offsets and the series ends yesterday
  9. Bangla toggle covers all static headings
  10. Lite mode removes SVG
  11. Editing a benchmark rate recomputes badges
  12. Weather API reachable or fallback active
  13. Implemented/Planned tag coverage
  14. Demo banner, skip link and lang on every route
  15. Copilot chips return cited non-fallback answers
  16. Copilot variant questions return cited non-fallback answers (English and Bangla)
  17. Copilot penalty, tender, rules and law questions return the procurement passage
  18. Copilot answers use Bangla text and digits in Bangla mode
  19. Every route has at least 800 characters of pre-rendered text in main
  20. No Latin-only visible labels in Bangla mode (acronyms and numbers allowed)

Limits: client-side checks can be altered by a user; this is not an independent audit or certification.
