Purpose

Prokolpo Tracker is a prototype that helps citizens review local public projects: progress, budget versus disbursement and material prices against benchmarks.

Test in 2 minutes

  1. Open /demo-user and save a report
  2. Open /demo-admin, run the audit scan and approve a log
  3. Open /app: price audit and projection
  4. Run /audit

Features and status

  • Schematic Bangladesh map (inline SVG, clickable divisions and ★ unions; not an official boundary) Implemented
  • Illustrative project drawings, original local SVG art (not photos of real sites; hidden in lite mode) Implemented
  • Animated opening page at / and a slow background animation (pausable, off with reduced motion or lite mode) Implemented
  • Division → District → Upazila → Union selectors (Bangla names, demo list) Implemented
  • 3 hand-authored unions (Ashulia, Birulia, Barabkunda), 10 synthetic projects Implemented
  • Price audit with 5% amber and 15% red thresholds Implemented
  • Disbursement-ahead-of-progress and past-deadline flags Implemented
  • Next-day statistical projection (least squares over 14 records) Implemented
  • Open-Meteo weather adjustment with offline fallback Implemented
  • Retrieval copilot (rule-based) with cited passages Implemented
  • Voice input via browser Web Speech API (bn-BD, en-US) Implemented
  • Knowledge graph (inline SVG) with details panel Implemented
  • Role view modes: Citizen, Journalist, Union Overseer Implemented
  • Lite mode (tables only, no SVG) Implemented
  • English / বাংলা toggle with Bangla digits and কোটি/লাখ Implemented
  • Anonymous local reports, confirm/flag, local approvals Implemented
  • In-browser audit with real checks Implemented
  • Real data from IMED, e-GP, PWD Planned
  • LLM assistant, vector search, agent orchestration, scrapers Planned
  • Real authentication (SSO, 2FA) and shared reporting backend Planned

Data sources

Only synthetic seed JSON and the optional Open-Meteo API. See /data.

Limitations

Names of unions are a demo list and must be verified with official LGD data. Benchmarks are illustrative. Votes and reports are not shared. Flags are advisory.

Ethics

All companies are fictional. The tool uses neutral language such as “Review recommended” and never accuses anyone. A human must decide.
