What this is

Prokolpo Tracker is a static web prototype. Citizens, journalists and auditors can drill down to a Union, view synthetic project data, compare billed prices with benchmark rates and try an anonymous report demo. Every flag is advisory; a human decides.

Honesty note

No login, no cookies, no external fonts. Pictures are illustrative drawings, not photos of real sites. The map is a schematic outline. Every feature carries an Implemented or Planned tag.
