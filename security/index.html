Security

Implemented controls

  • No login anywhere Implemented
  • No cookies set by this site Implemented
  • No third-party trackers or analytics Implemented
  • No external fonts or CDNs (system fonts only) Implemented
  • User actions stored only in localStorage on your device Implemented
  • User-supplied text is HTML-escaped (including quotes); no inline event handlers Implemented
  • Content-Security-Policy meta tag: scripts only from this site; network only to this site and Open-Meteo Implemented
  • Anonymous reports: this static site stores no IP address and sends nothing Implemented

Third-party interactions (complete list)

  • Open-Meteo weather request: when a page needs a forecast, your browser contacts api.open-meteo.com, so Open-Meteo can see your IP address. No key and no personal data are sent. If it fails, the app says weather was not applied. Implemented
  • Voice input: it uses your browser Web Speech API. In some browsers (for example Chrome) the audio is processed by the browser vendor’s speech service, outside this site. It starts only when you press the microphone button; typing is always available. Implemented
  • Google Maps link: the Open in Google Maps button is a plain link. Nothing is requested from Google unless you click it, and it opens in a new tab on google.com under Google’s own terms. This site embeds no Google content. Implemented
  • Hosting: static files are served by the host (GitHub Pages), which may keep ordinary server logs outside this site’s control. Hosting is not in a Bangladesh region. Implemented

Planned (not built)

  • Single sign-on Planned
  • Two-factor authentication Planned
  • Encryption at rest (there is no server database yet) Planned
  • Bangladesh-region hosting Planned
  • Formal security and privacy audits Planned

Limits: the CSP allows inline styles for layout. The host (Vercel or GitHub Pages) can see normal web server logs; that is outside this app. No certification is claimed.

Data sovereignty

The prototype holds only synthetic data. Citizen actions never leave the device. Hosting location is decided by the static host you choose, so no in-country claim is made.

Responsible AI

  • Human in the loop: every flag is advisory and a person decides.
  • Sources shown: each answer cites its passage or data; projection shows formula and inputs.
  • Bias note: benchmarks ignore location, transport and bulk discounts, which can flag some areas more often.
  • Limitations: synthetic data, small sample, simple statistics, not a legal finding.
